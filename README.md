# 21Days_Of_SQL
21 Days of SQL – Building consistency,Learning, practicing, and growing daily..

---
## 📌 Overview

The **21 Days SQL Challenge** by Indian Data Club is a structured learning program designed to build strong SQL fundamentals through daily practice and real-world datasets.

This challenge covers everything from basic queries to advanced SQL concepts like joins, subqueries, and data analysis. Each day focuses on a specific topic along with hands-on problems, helping learners develop practical data querying skills.

Although I started this challenge later, I successfully completed it to strengthen my SQL knowledge and consistency in learning.

---

## 📅 Learning Journey (Day-wise)

| Day | Topic | What I Learned |
|-----|------|---------------|
| Day 1 | SELECT | Basics of retrieving data and selecting columns |
| Day 2 | WHERE | Filtering data using conditions |
| Day 3 | ORDER BY | Sorting data in ascending/descending order |
| Day 4 | LIMIT & OFFSET | Controlling result size and pagination |
| Day 5 | Aggregate Functions | COUNT, SUM, AVG, MIN, MAX usage |
| Day 6 | GROUP BY | Grouping data for analysis |
| Day 7 | HAVING | Filtering grouped data |
